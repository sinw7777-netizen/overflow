### 📌 프로젝트 소개 (Team Overflow)
대학별·전형별로 상이한 편입학 모집요강을 한곳에서 비교하고, 목표 대학의 준비 현황을 체계적으로 관리할 수 있는 모바일 웹 서비스 프로토타입입니다.

* **주요 26개 대학 요강 및 입학처 직통 연결**: 지원 자격·학점, 시험 과목, 공인어학 기준, 원서 일정을 4대 영역으로 구조화하여 제공
* **실시간 목표 대학 순위 변경**: 드래그 앤 드롭(터치/마우스) 핸들을 통한 지망 순위(1~N순위) 즉시 재배열 및 1순위 대표 대학 엠블럼 워터마크 반영
* **대학별 독립 체크리스트 & 개인 메모**: 목표 대학별 필수 준비 항목 달성률(%) 추적 및 JSON 데이터 백업·복원 지원
* **지능형 전형 가이드**: 일반편입 미선발 대학(서울대 등) 선택 시 전형 자동 제어 및 안내 배너 제공
