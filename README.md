## 3. PRD (제품 요구사항 정의서)

### 3.1 기획 배경 및 문제 정의
* 대학 편입학은 대학별·전형별(일반편입·학사편입)·계열별(인문·자연)로 지원 자격(이수 학점), 시험 과목(편입영어·편입수학·공인영어), 원서 접수 일정이 모두 상이함.
* 수험생은 보통 5~10개 이상의 대학에 복수 지원하므로 입학처 공지사항을 개별 확인하고 준비 현황을 수기로 관리하는 과정에서 높은 피로도와 누락 위험이 발생함.
* **해결 목표**: 다중 목표 대학의 전형 요건을 4대 영역으로 표준화하여 한눈에 비교하고, 지망 우선순위와 대학별 체크리스트를 단일 모바일 웹 화면에서 통합 관리함.

### 3.2 핵심 기능 요구사항

| 영역 | 기능명 | 상세 명세 | 구현 상태 |
|---|---|---|---|
| **홈 대시보드** | 진행률 및 1~3순위 퀵 스위처 | 현재 선택 대학의 체크리스트 달성률(%) 표시 및 상위 1~3순위 탭 전환 지원 | 완료 |
| **우선순위 관리** | 드래그 앤 드롭 순위 재배치 | 목표 대학 카드 우측 핸들(`≡`) 드래그(터치/마우스)로 1~N순위 실시간 변경 | 완료 |
| **AI 요강 탐색** | 26개교 모집요강 자동 추출 | 대학·연도·전형·학과 입력 시 계열(인문/자연)을 판별해 4대 영역 요강 생성 | 완료 |
| **전형 예외 제어** | 일반편입 미선발 대학 자동 고정 | `서울대` 선택 시 경고 배너를 노출하고 일반편입 비활성화 및 학사편입 자동 고정 | 완료 |
| **준비사항 요약** | 4대 영역 조회 및 개인 메모 | `지원 자격·학점`, `시험 과목·범위`, `어학·자격증`, `제출 서류·일정` 상세 및 메모 저장 | 완료 |
| **체크리스트** | 대학별 독립 4단계 점검표 | 목표 대학별 필수 준비 4항목 독립 체크 및 달성률 자동 산출 | 완료 |
| **계정 및 설정** | 로그인 모달·약관·백업/복원 | 계정 로그인 및 개인정보 처리방침 고지, 1순위 대학 엠블럼 워터마크, JSON 백업 | 완료 |

## 6. 배포 및 버전 관리 방법

### 6.1 GitHub Pages 배포 설정
* **Settings → Pages → Build and deployment**: Source `Deploy from a branch` → Branch `main` / `/ (root)`

### 6.2 버전 업그레이드 시 업데이트 절차
1. **단일 실행 파일 아카이브**: `pages/` 폴더에 새 버전 파일(`ver0.7.html` 등)을 업로드한 뒤 `README.md` 상단 표의 실행 링크 파일명을 함께 수정함.
2. **루트 분리 파일 동기화**: 루트 경로 배포본을 갱신할 때는 `index.html`, `css/style.css`, `js/app.js`, `data/universities.json` 4개 파일을 한 세트로 함께 커밋함.
3. **로컬 확인 방법**:
   ```bash
   python3 -m http.server 5500
   # 브라우저에서 http://localhost:5500 접속
   ```
